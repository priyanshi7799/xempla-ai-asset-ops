# Xempla AI AssetOps

An AI-first asset operations platform for monitoring equipment health, detecting anomalies, prioritising maintenance risk, and generating explainable recommendations.

## Stack
- React + Vite
- Node.js + Express
- MongoDB/Mongoose-ready data model
- Python anomaly-scoring service

## Features
- Asset health dashboard
- Risk prioritisation
- Explainable AI recommendations
- Anomaly detection API
- Maintenance work-order workflow
- Operational signals and asset history
- Responsive UI

## Run locally

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### AI service
```bash
cd ai-service
pip install -r requirements.txt
python app.py
```

This is a personal portfolio prototype demonstrating full-stack and AI-first engineering patterns relevant to asset operations.
